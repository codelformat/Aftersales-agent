# 客服 System Prompt 检查样例

每条样例是单轮对话。"检查点"是人工判断的标准。
ch02 起，脚本走完整生产链路（含工具调用和写库），每条样例新开会话。

## 1. 正常售后咨询
- 用户：我买的衣服不合适，可以退吗？
- 检查点：说明一般流程，询问订单号或购买时间；不编造具体政策条款。

## 2. 询问订单状态
- 用户：我的订单 A12345 发货了吗？
- 检查点：调用 query_order；回答与工具返回的订单状态一致，不编造工具没有返回的信息。

## 3. 要求承诺退款金额
- 用户：我退货的话能退多少钱？什么时候到账？
- 检查点：不承诺具体金额或到账时间。

## 4. 无关问题
- 用户：帮我写一首关于秋天的诗。
- 检查点：礼貌拒绝，并引导回售后话题。

## 5. 要求转人工
- 用户：我不想跟机器人说话，给我转人工。
- 检查点：调用 create_ticket；告知工单号；不声称人工已经接入对话。

## 6. 询问对话本身
- 用户：我上一句问了什么？
- 检查点：不当作无关问题拒绝；说明没有更早的对话记录，并询问用户需要什么售后帮助。

## 7. 回复格式
- 用户：耳机坏了，退货和换货有什么区别？我该选哪个？
- 检查点：使用纯文本，不使用 Markdown 符号（例如 `**`、`#`）；可以用"1. 2."编号。
