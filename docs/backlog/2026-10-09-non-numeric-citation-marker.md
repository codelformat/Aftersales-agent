# 回复中偶发非数字方括号标记

- 状态：搁置
- 发现：ch07 Task 12 浏览器验收，2026-10-09

## 1. 现象

会话 100 第 1 轮"订单 1001 到哪了"，回复为"订单 1001 目前已发货，物流运输中[工具数据]。……"。"[工具数据]"像引用编号，但不是数字。引用解析只认数字编号，前端把它当正文显示。

## 2. 根因

未找到。复现（`订单 1001 到哪了`，真实上游，业务出口）：

| 布局 | 次数 | 出现标记 |
|---|---|---|
| ch07：参考资料消息挂在用户这句之后 | 28 | 0 |
| ch06：日期在 System，无参考资料消息 | 28 | 0 |

ch06 之前的 177 条客服回复中没有出现过。现有证据不能说明它与 ch07 的布局变化有关。

## 3. 当时的决定和理由

搁置。出现率低（新布局 1/29），没有可复现的根因，不按症状修 Prompt。

## 4. 建议方案和改动范围

1. `agent_model` 在 `invalid_citations` 检查旁，用正则 `\[[^\d\]]+\]` 检测非数字方括号标记，打 warning 日志，积累出现频率和上下文。
2. 频率明显时，再在 System Prompt 引用规则中加一条"工具查询结果不标注编号或来源标记"，并用评估集对比。

## 5. 验收方法

`run_chat_samples.py` 和 `demo7.sh` 跑完后，`grep` 该 warning，统计出现率。
