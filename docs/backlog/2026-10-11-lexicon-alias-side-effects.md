# ch12 新同义词改写了无关的生产查询

- 状态：搁置（等用户决定）
- 发现：ch12 整个分支的 code review，2026-10-11

## 1. 现象

`knowledge/lexicon.json` 中 ch12 新增的同义词对所有查询生效。重排 query 用 `dense_query()`，它把俗称替换成标准词：

| 原问题 | `dense_query()` 结果 |
|---|---|
| 电子发票几天发出？ | 电子发票发货？ |
| 维修好了啥时候发回来？ | 维修好了发货回来？ |
| 退货时要自己把商品退回快递点吗？ | 退货时要自己把商品拒收点吗？ |
| 定金和预付款有什么区别 | 定金和定金有什么区别 |

`bm25_query()` 会把"发货""拒收"等词追加到 BM25 查询中。

## 2. 根因

spec 1.4 为新政策加了 5 个同义词条。其中"几天发出""啥时候发""退回快递""预付款"在发货、拒收、定金以外的语境也很常见。`dense_query()` 按子串替换，不判断语境。

## 3. 当时的决定和理由

搁置，由用户决定。删除别名会改变检索结果，需要重跑新知识库上的 3 次评估（v2、旧 300 题、ch11 困难题集），而 ch12 报告的数字都来自这份词表。

## 4. 建议方案和改动范围

- 删除"几天发出""啥时候发""退回快递""预付款"4 个别名，保留"订金""不签收""没货""断货""预订""提前订"。只改 `knowledge/lexicon.json`。
- 加一条测试：上表 4 个问题经 `dense_query()` 后不变。
- 重跑 `evals/reports/ch12_comparison.md` 中运行 3、4、5，更新报告。

## 5. 验收方法

上表 4 个问题的 `dense_query()` 输出与原问题相同；3 次评估的日志中余额错误为 0。
