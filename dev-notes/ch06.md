  | 问题 | 决策 |
  |---|---|
  | 退款单 | `POST /refunds` mock，返回退款单号，提示写 `messages` 表和 State，不落库 |
  | 纯政策问题 | `resolve_reference` 输出 `order_scoped`；为假时跳过订单节点，仍扩写和强制检索 |
  | 降级路 | `INTENT_SMALL_MODEL`（默认 `None`）+ `INTENT_ESCALATE_BELOW=0.7`，代码和测试本章完成 |
  | 订单选择器 | `ensure_order` 调 `interrupt()`；API 发 `order_picker` + `done(interrupted)`；`/chat/resume` 用 `Command(resume=order_id)` 继续 |

- Context7 核对：`interrupt()` 恢复时节点从头重新执行，`interrupt()` 之前不能有副作用；所以卡片由 API 层发，不由节点发。
